Provably fair — how each result is made

Every flip and every case roll comes from one hash. The server seed is generated in your browser with crypto.getRandomValues and shown below so you can check the maths yourself. Nothing is fetched, nothing is sent anywhere — open devtools and watch the network tab stay empty.

Verify with any HMAC tool: key = server seed, message = clientSeed:nonce, SHA-256, hex output. The first 8 characters, read as a hex integer and divided by 4294967296, give the number in [0, 1) that decides the roll.
